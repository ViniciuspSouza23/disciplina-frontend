# Meu Primeiro Projeto React - Frontend

Projeto desenvolvido como atividade prática da disciplina **Frameworks Front-end**, ministrada pelo Prof. Me. Deivison S. Takatu, com base na Aula 02 - Configuração do Ambiente de Desenvolvimento.

## 📚 Resumo da Aula

A Aula 02 abordou os conceitos e ferramentas fundamentais para a configuração de um ambiente de desenvolvimento front-end moderno. Os principais tópicos trabalhados foram:

- **Versionamento x Backup**: diferença entre um sistema de controle de versão (histórico completo, rastreabilidade e colaboração) e um simples backup (cópia pontual sem rastreio de autoria).
- **Versionamento Semântico (SemVer)**: padrão `MAJOR.MINOR.PATCH` utilizado para identificar mudanças em um software, indicando correções de bugs, novas funcionalidades compatíveis e alterações que quebram compatibilidade.
- **Git e Controle de Versão**: instalação e configuração do Git, incluindo os comandos `git config --global user.name` e `git config --global user.email`.
- **Tags, Branches e Boas Práticas no Git**: uso de tags para marcar versões estáveis do projeto (`git tag`), organização por branches e recomendações como commits pequenos, mensagens claras e testes antes do merge.
- **IDE e Visual Studio Code**: uso do VS Code como ambiente integrado de desenvolvimento, com suporte a extensões e controle de código-fonte.
- **Node.js e NPM**: instalação do Node.js (ambiente de execução JavaScript no backend) e do NPM (gerenciador de pacotes responsável por instalar e gerenciar as dependências do projeto via `package.json`).
- **Criação de Projetos React**: uso do comando `npx create-react-app` para gerar a estrutura inicial de uma aplicação React, incluindo Webpack, Babel e servidor de desenvolvimento local.
- **Deploy e Hospedagem com Vercel**: publicação de aplicações modernas com integração automática ao GitHub, deploys instantâneos, CDN global e suporte a frameworks como React, Next.js e Vue.

## 🎯 Proposta da Atividade

A atividade proposta consistia em:

1. Desenvolver uma aplicação React utilizando o **Visual Studio Code** como ambiente de desenvolvimento.
2. Utilizar o **Git** para versionar o projeto, realizando commit e push para um repositório no **GitHub**.
3. Após publicar o código no GitHub, realizar o **deploy da aplicação na Vercel**, conectando o repositório para publicação automática.
4. Disponibilizar o projeto online por meio de uma **URL pública da Vercel**.

## 🚀 Sobre o Projeto

Este repositório representa a aplicação React desenvolvida para cumprir a atividade prática proposta na aula, colocando em prática todo o fluxo de configuração de ambiente, versionamento com Git/GitHub e deploy contínuo com a Vercel.

## ⚙️ Como Executar Localmente

```bash
# Clonar o repositório
git clone https://github.com/ViniciuspSouza23/meu-primeiro-projeto-react-frontend.git

# Acessar a pasta do projeto
cd meu-primeiro-projeto-react-frontend

# Instalar as dependências
npm install

# Iniciar o servidor de desenvolvimento
npm start
```

O projeto ficará disponível em `http://localhost:3000`.
