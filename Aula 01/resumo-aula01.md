# 🚀 Pitch do Projeto

Este projeto foi desenvolvido como parte da **Atividade 01** da disciplina **Frameworks Front-end**. Seu principal objetivo é colocar em prática os fundamentos do desenvolvimento Front-end utilizando apenas tecnologias nativas da Web, compreendendo o fluxo completo de criação, versionamento e publicação de uma aplicação.

Além da implementação da interface, a atividade introduz o uso de ferramentas amplamente utilizadas no mercado, preparando a base para os próximos projetos e conteúdos que serão desenvolvidos durante o semestre.

---

# 📝 Sobre a Aula

A Aula 01 teve como objetivo apresentar a disciplina **Frameworks Front-end**, abordando o plano de ensino, metodologia, critérios de avaliação, conteúdos programáticos e as ferramentas que serão utilizadas durante o semestre.

## Também foi apresentada a importância do desenvolvimento Front-end, do JavaScript Vanilla como base para frameworks modernos e do fluxo de desenvolvimento utilizando Git, GitHub e Vercel.

# 📚 Resumo da Aula

Durante a aula foram apresentados os seguintes conteúdos:

* Apresentação da disciplina;
* Plano de ensino;
* Objetivos da unidade curricular;
* Metodologia de ensino;
* Critérios de avaliação;
* Introdução ao desenvolvimento Front-end;
* Conceitos iniciais sobre JavaScript (Vanilla JS);
* Introdução ao Git e GitHub;
* Publicação de aplicações utilizando Vercel.

Esses conceitos representam a base para o desenvolvimento das atividades que serão realizadas ao longo da disciplina.

---

# 💻 Descrição do Projeto

O projeto consiste em uma aplicação Web desenvolvida utilizando apenas **HTML5**, **CSS3** e **JavaScript (Vanilla JS)**, sem a utilização de frameworks ou bibliotecas externas.

Durante seu desenvolvimento foram aplicados conceitos de estruturação de páginas, estilização de interfaces, manipulação básica do DOM, organização do projeto, versionamento com Git e publicação da aplicação utilizando a plataforma Vercel.

Além de representar a primeira atividade prática da disciplina, o projeto demonstra o fluxo básico de desenvolvimento Front-end adotado em projetos reais.

---

# 🎯 Função do Projeto

O projeto possui como finalidade:

* Aplicar os conceitos apresentados na Aula 01;
* Desenvolver uma aplicação utilizando tecnologias Web nativas;
* Praticar a organização de projetos Front-end;
* Utilizar Git para controle de versão;
* Publicar aplicações utilizando GitHub e Vercel;
* Servir como base para os próximos projetos da disciplina.

---

# ✅ Atividade 01

A primeira atividade prática consistiu em:

* Desenvolver uma aplicação utilizando HTML, CSS e JavaScript (Vanilla JS);
* Configurar o ambiente de desenvolvimento;
* Criar um repositório no GitHub;
* Versionar o projeto utilizando Git;
* Publicar a aplicação utilizando a plataforma Vercel.

A atividade permitiu compreender todas as etapas básicas do ciclo de desenvolvimento Front-end, desde a implementação da aplicação até sua disponibilização na Web.
