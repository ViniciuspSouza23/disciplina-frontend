# 📚 Frameworks Front-end

Repositório desenvolvido para a disciplina de **Frameworks Front-end**, ministrada pelo **Prof. Me. Deivison S. Takatu** no SENAI.

Este repositório tem como objetivo reunir os **resumos das aulas**, atividades práticas e projetos desenvolvidos ao longo do semestre, servindo como um material de apoio para estudos, revisões e acompanhamento da evolução na disciplina.

---

# 🎯 Objetivos

Este repositório possui os seguintes objetivos:

* Organizar os resumos de todas as aulas da disciplina;
* Documentar as atividades propostas durante o semestre;
* Registrar a evolução do aprendizado em desenvolvimento Front-end;
* Consolidar conceitos por meio de exemplos práticos;
* Construir um portfólio acadêmico com os projetos desenvolvidos.

---

## 📖 Sobre a Disciplina

A disciplina **Frameworks Front-end** tem como objetivo desenvolver competências para criação de aplicações Web modernas, responsivas e organizadas, utilizando tecnologias e frameworks amplamente adotados pelo mercado.

Ao longo do semestre serão estudados conceitos como desenvolvimento Front-end, JavaScript (Vanilla JS), frameworks CSS e Front-end, componentização, boas práticas, versionamento com Git e GitHub e deploy de aplicações Web.


# 📚 Conteúdos Estudados

Ao longo do semestre, este repositório será atualizado com resumos e atividades referentes aos seguintes conteúdos:

* Desenvolvimento Front-end;
* HTML5, CSS3 e JavaScript (Vanilla JS);
* Responsividade;
* Ferramentas do Desenvolvedor;
* Git e GitHub;
* Deploy de aplicações;
* Frameworks CSS;
* Frameworks Front-end;
* Componentização;
* Gerenciamento de estados;
* Rotas;
* Desenvolvimento de interfaces modernas;
* UX (User Experience);
* Boas práticas de desenvolvimento.

Os conteúdos seguem o plano de ensino da disciplina e têm como foco preparar o estudante para o desenvolvimento de aplicações Web modernas e alinhadas às práticas utilizadas pelo mercado.
